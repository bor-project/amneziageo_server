# {{ page.title }}

Утилита - консоль сервера: она работает с той же базой, что панель, и делает то, что не делается через HTTP до первого входа, да и всё остальное из скриптов. {% if page.kind == "docker" %}В контейнере она зовётся `docker compose exec panel amneziageo-server <команда>` из каталога проекта (по умолчанию `/opt/amneziageo-docker`); меню `amneziageo-server` на хосте, если при установке его поставили на хост, передаёт ей неизвестные себе команды: `amneziageo-server user list`.{% else %}Она лежит в релизе как `/opt/amneziageo-server/AmneziaGeo.Server.Cli`, а меню `amneziageo-server` передаёт ей команды, которых не знает само: `amneziageo-server user list`. Член группы `amneziageo` запускает её без `sudo`; чтение интерфейсов ядра требует root.{% endif %} `amneziageo-server help` печатает команды меню, утилита без команды - свои.

Пароль утилита спрашивает в терминале; `--generate` придумывает его и печатает один раз, `--permanent` не требует смены при первом входе. Команды, которые что-то удаляют, спрашивают подтверждение, `--yes` отвечает за вас.

## Вход и учётные записи

| Команда | Что делает |
|---|---|
| `init [--user <логин>] [--generate] [--permanent]` | первый администратор, пока в панели нет включённого; без `--user` - учётная запись хоста, от которой запущена утилита{% if page.kind == "docker" %} (в контейнере `--user` обязателен){% endif %}. Последней строкой называет порт и путь панели |
| `login [--user <логин>] [--json]` | войти и напечатать токены сессии |
| `refresh <токен>` | обменять токен обновления на новую пару |
| `whoami` | что панель думает об учётной записи хоста, от которой запущена утилита |
| `user list` | учётные записи с ролью и состоянием |
| `user add <логин> [--role <роль>] [--host [--key <открытый ключ>]] [--generate] [--permanent]` | учётная запись панели; `--host` делает её и пользователем хоста с ключом ssh |
| `user passwd <логин> [--generate] [--permanent]` | новый пароль |
| `user role <логин> <роль>` | роль |
| `user enable`, `disable`, `remove <логин>` | включить, выключить, удалить |
| `role list`, `role add <код> [--title <название>] <право>...`, `role set <код> [--title <название>] [<право>...]`, `role remove <код> [--yes]` | роли; права - `state:read`, `clients:write`, `interfaces:write`, `routing:write`, `access:write`, `updates:write`, `backup:read` |
| `token list`, `token add <название> --role <роль> [--days <n>]`, `token revoke <id> [--yes]` | токены для скриптов; секрет печатается один раз последней строкой |

## Панель

| Команда | Что делает |
|---|---|
| `panel show` | где отвечает панель |
| `panel get port`, `path`, `listen`, `domains`, `certificate`, `key`, `opened`, `channel` | одно значение, для скриптов |
| `panel set [--port <n>] [--path <путь> | random | /] [--listen <адреса> | all] [--domains <имена> | none] [--certificate <цепочка> --key <ключ> | --certificate none] [--opened on | off] [--channel stable | test]` | настройки вкладок «Сервер» и «Сертификаты»; `--opened` держит порт панели открытым в брандмауэре, `--channel` - канал релизов. Данная до первого старта, записывает настройки первой, см. [Первый старт](panel/server.ru.html#первый-старт) |
| `panel reset [--yes]` | `127.0.0.1`, порт 8443, новый случайный путь, без сертификата |
| `subscriptions show`, `subscriptions get <имя>`, `subscriptions set --opened on | off` | подписки: показать, одно значение, держать порт открытым |
| `update status`, `update check`, `update apply [--beta]` | обновление: как прошло последнее, посмотреть релизы сейчас, поставить новейший; меню зовёт `apply` в пунктах 2 и 3 |
| `backup check <файл>` | проверить файл копии базы |

Настройки меняются в базе; панель берёт адрес, порт, путь и сертификат после перезапуска, меню перезапускает её само после каждого `panel set`.

## Интерфейсы и клиенты

| Команда | Что делает |
|---|---|
| `endpoint list` | интерфейсы с портом и тем, кто держит порт открытым: панель или хост |
| `endpoint open <имя>`, `endpoint close <имя>` | держать порты интерфейса открытыми в брандмауэре или оставить хосту |
| `import endpoint <файл.conf> [--name <имя>] [--host <адрес>] [--dns <список>] [--allowed <список>]` | интерфейс из файла `awg-quick`, с ключами и обфускацией |
| `import peers <файл.conf> [--endpoint <имя>]` | пиры файла интерфейса как клиенты без приватных ключей |
| `import clients <файл.json> [--endpoint <имя>] [--v6 <префикс>]` | клиенты из файла, в котором хост держал их с приватными ключами |
| `device list` | интерфейсы `amneziawg` в ядре |
| `device show [имя] [--secrets]` | интерфейс с пирами, как его держит ядро |
| `device set <имя> [--key <base64>] [--generate] [--port <n>] [--fwmark <n>] [--shape jc=4,jmin=40,...] [--i1 <спец>] [--hpk <base64>]` | записать настройки интерфейса в ядро напрямую, для отладки |
| `device peer <имя> <публичный ключ> [--allowed <a,b>] [--endpoint <хост:порт>] [--preshared <base64>] [--keepalive <с>] [--replace-ips] [--update-only] [--remove]` | пир интерфейса в ядре, для отладки |
| `family [имя]` | номер семейства netlink |

Команды `device` и `family` говорят с ядром, минуя базу панели: что они изменили, панель при следующем применении положит обратно по своим настройкам. Клиенты, правила, каналы и шаблоны из консоли не редактируются: это [HTTP API](../api.ru.html) с токеном от `token add`.

## Гео и DNS

| Команда | Что делает |
|---|---|
| `geo update` | скачать включённые гео-источники сейчас |
| `dns show` | настройки резолвера |
| `dns get enabled`, `port`, `upstreams`, `encrypted`, `outbound` | одно значение; `encrypted` - `all`, `none` или `partly`, спрашиваются ли внешние серверы шифрованно |
| `dns set --enabled on | off [--upstreams <серверы> | default]` | включить или выключить резолвер, задать внешние серверы или вернуть те, с которых начинает свежая панель |

Меню `amneziageo-server dns on` и `dns off` зовут то же с вопросами.

## Пример

Токен на сутки, список клиентов через API и его отзыв:

```
amneziageo-server token add nightly --role admin --days 1
curl -s -H "Authorization: Bearer agt_..." https://panel.example.com:8443/api/clients
amneziageo-server token revoke <id> --yes
```

Все команды принимают `--db <файл>`, чтобы работать с другой базой, например с копией.
