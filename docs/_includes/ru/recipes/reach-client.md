# {{ page.title }}

Задача: за одним из клиентов стоит устройство, до которого нужно добираться через туннель: домашний компьютер, NAS, камера. По умолчанию клиентов интерфейса из туннеля не достают: соединение к клиенту начинает только он сам.

## 1. Доступ на сервере

«Клиенты» > клиент `home-nas` > «Настройки» > «Доступ»: «Доступ к клиенту»:

| Значение | Кто достаёт клиента |
|---|---|
| Закрыт | никто из туннеля |
| Только сервер | панель и хост сервера: для сигнала отключения, проверок и служб на сервере |
| Вся сеть туннеля | все клиенты интерфейса: другой клиент достаёт `home-nas` по его адресу в туннеле |
| Как у интерфейса | что стоит в «Доступ к клиентам» интерфейса |

Для доступа с других устройств - «Вся сеть туннеля». Чтобы так было у всех клиентов интерфейса сразу, то же ставится в «Доступ к клиентам» интерфейса, а отдельный клиент оставляется с «Как у интерфейса». Панель кладёт это правилами брандмауэра интерфейса, см. [Интерфейсы](../panel/interfaces.ru.html#что-кладётся-на-хост).

## 2. Доступ на устройстве

Само устройство тоже должно пускать соединения из туннеля. В клиенте AmneziaGeo это «Разрешить входящие подключения из VPN-сети» в настройках конфигурации или из консоли `amneziageo config inbound <имя> network` (`host` - только для сервера). Файл конфигурации и ссылка `vpn://` этого не несут: hello передаёт приложению, что разрешил сервер, но решение остаётся за устройством. Брандмауэр самого устройства тоже должен пускать нужный порт.

## 3. Проверка

С другого клиента того же интерфейса откройте адрес `home-nas` в туннеле, например `10.8.0.7`, нужным портом. Адрес виден в списке клиентов. Клиенты с «Закрыт» и «Только сервер» на этот запрос не ответят, пакеты до них отбрасываются на сервере.

## Что ещё

- Два клиента одного интерфейса достают друг друга только через сервер и его правила; клиенты разных интерфейсов не видят друг друга.
- «Только сервер» нужен, чтобы панель доставила сигнал отключения выключенному клиенту: сигнал идёт с адреса интерфейса на порт приложения внутри туннеля, см. [Отключение клиента](../panel/clients.ru.html#отключение-клиента).
- Сеть за устройством (другие машины дома) этим рецептом не достаётся: для неё нужны маршруты на обеих сторонах, которых панель не ставит.
