# {{ page.title }}

Задача: перевезти панель с клиентами, интерфейсами и настройками на новый хост так, чтобы клиенты продолжили подключаться со своими конфигурациями. Копия базы несёт всё, кроме сертификата, ключа подписи токенов и файлов гео.

## 1. Копия на старом хосте

«Обзор» > «Резервная копия» > «Скачать копию» (право «Скачивание бэкапа»). Файл `amneziageo-<имя>-<время>.db` несёт учётные записи и токены, интерфейсы с ключами, клиентов, шаблоны, правила, каналы и настройки панели. Из консоли копию снимает пункт 5 меню, подпункт 5, в каталог `backup` рядом с базой.

## 2. Панель на новом хосте

Скопируйте файл на новый хост и поставьте панель на нём:

```
amneziageo-server install --restore /root/amneziageo-<имя>-<время>.db
```

Скрипт проверяет файл, ставит панель {% if page.kind == "docker" %}контейнером{% else %}службой{% endif %}, откладывает свежую базу в `backup` и запускает панель на копии; администратора и интерфейс он не заводит, они уже в копии. Если панель на новом хосте уже стоит, то же делает `amneziageo-server restore <файл>` или «Восстановить из файла» на «Обзоре» (копия с адресами, которых у хоста нет, из панели не встаёт, консольная команда подгоняет её под хост).

## 3. Имя

Клиенты ходят на сервер по имени из своих конфигураций, строка `Endpoint`. Переведите имя в DNS на адрес нового хоста; конфигурации клиентов менять не нужно. Если в `Endpoint` стоял адрес, а не имя, клиентам понадобятся новые файлы: подписка отдаст их сама, как только хост интерфейса исправлен на новый адрес.

## 4. Сертификат и порты

Сертификат панели в копию не входит. Скрипт предлагает выпустить сертификат Let's Encrypt на то же имя, когда имя уже указывает на новый хост; иначе панель отвечает без сертификата, пока его не поставит пункт 22 меню. Адреса старого хоста, на которых слушала панель, скрипт отбрасывает. Порты интерфейсов, панели и подписок, которые панель держала открытыми, она откроет в брандмауэре нового хоста сама при старте; ufw на новом хосте включает установка или пункт 23 меню.{% if page.kind == "docker" %} Панель в контейнере до ufw хоста не достаёт: на хосте с включённым ufw порты открывает пункт 23 меню на хосте или `ufw allow <порт>`.{% endif %}

## 5. Проверка

Карточка «Службы» на «Обзоре»: интерфейсы поднялись, подписки и резолвер отвечают, сертификат на месте. Клиент с устройства подключается без правок. Гео-источники панель скачивает сама после запуска.

## 6. Старый хост

Остановите панель на старом хосте (`amneziageo-server stop` и `disable`), чтобы клиенты, у которых имя ещё не обновилось в кэше, не ходили на оба сервера. Ключ подписи токенов на новом хосте новый: сессии в браузерах и токены сессий кончатся, войти придётся заново; долгоживущие токены для скриптов (`agt_...`) живут в базе и работают дальше.
