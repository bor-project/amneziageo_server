# {{ page.title }}

Задача: клиенты получают список сайтов, которые идут через VPN, а остальное у них идёт напрямую, и этот список ведёт сервер. Есть два пути: `AllowedIPs` в файле клиента, который понимает любое приложение AmneziaWG, и пресеты маршрутизации, которые понимает приложение AmneziaGeo.

## Через AllowedIPs: шаблон

«Клиенты» > «Шаблоны» > «Добавить»: имя `split`, в «Маршрутизация» записи вроде `geosite:youtube`, `geoip:ag-youtube`, `geosite:telegram`, `example.com`. Панель разворачивает записи в диапазоны адресов, и это идёт в `AllowedIPs` файла каждого клиента шаблона; «Адресов: N» под записями говорит, сколько вышло. «Сохранить», затем у нужных клиентов «Шаблон» `split`.

Так работает любой клиент WireGuard: он отправляет в туннель только адреса из файла. Но адреса сервисов меняются, а в файле они стоят, пока шаблон не пересчитали кнопкой «Обновить» и клиент не получил новый файл через подписку. Сервисы за CDN с тысячами адресов дают длинный список: панель предупреждает о замедлении после 12000 диапазонов и не сохраняет шаблон после 16000. Подробнее - [Шаблоны](../panel/templates.ru.html).

## Через пресеты: приложение AmneziaGeo

Приложение AmneziaGeo само следит за ответами DNS и кладёт адреса из своих списков в туннель на лету. Список для него ведётся на сервере пресетом.

1. «Клиенты» > «Пресеты маршрутизации» > «Добавить»: имя `Недоступные сайты`, в «Через VPN» те же записи, `geosite:youtube`, `geoip:ag-youtube`, `geosite:telegram`; в «Блокировать» можно `geosite:category-ads-all`. «Включён по умолчанию», чтобы приложение включило список, когда добавит его. «Весь UDP через туннель» - для звонков и игр, которые узнают адреса не через DNS. «Сохранить».
2. «Клиенты» > «Шаблоны» > шаблон клиентов > «Пресеты маршрутизации»: отметьте пресет, «Сохранить». Записи шаблона в «Маршрутизация» оставьте пустыми: `AllowedIPs` остаётся `0.0.0.0/0`, а что идёт в туннель, решает приложение по списку.
3. Приложение при следующем hello добавляет список и включает его. Вместе с пресетом оно получает гео-источники панели со страницы [Списки Geo](../panel/geo.ru.html), так что ключи `ag-` собственной базы у него тоже есть.

Правка пресета меняет его время изменения, и карточка списка в приложении предлагает обновление; хозяин устройства принимает его или оставляет своё. Список, который хозяин удалил, возвращается при следующем hello. Подробнее - [Пресеты маршрутизации](../panel/presets.ru.html).

## Что выбрать

Пресеты - для приложения AmneziaGeo: список живой, обновляется сам и не раздувает файл. Шаблон с записями - для любого другого клиента и для случаев, когда маршрутизация должна быть зашита в файл. Оба пути можно совмещать: шаблон с записями для чужих приложений, пресет для своих, но тогда `AllowedIPs` ограничит и приложение AmneziaGeo тем, что в файле.

Маршрутизация на сервере - правила раздела [Маршрутизация](../panel/routing.ru.html) - решает другое: куда трафик идёт после сервера.
