# {{ page.title }}

Подписка - адрес, с которого приложение клиента читает свои конфигурации и к которому возвращается само. Каждый клиент несёт имя подписки, а подписка несёт всех клиентов под этим именем, так что один человек с несколькими устройствами читает их с одного адреса. Клиенту без приватного ключа и выключенному клиенту в подписку нечего отдать.

## Раздача

«Сохранить» вступает в силу сразу: панель заново поднимает порт подписок, а если хост его не дал, оставляет прежние настройки и пишет причину под кнопками.

| Поле | Что задаёт |
|---|---|
| Включено | раздаёт ли панель подписки; по умолчанию нет |
| Отдельный порт | подписки на своём порту; снято - «Сертификат панели»: подписки рядом с панелью на её порту, под её сертификатом |
| Слушать на адресах | адреса хоста для своего порта; пусто - все. На порту панели не учитывается |
| Отвечать доменам | имена, на которые отвечают подписки; первое идёт в адрес, который выдаётся клиенту |
| Порт | 2096 по умолчанию. Закрытый брандмауэром порт назван под полем с кнопкой «Открыть» или «Открыть при сохранении» и не сохраняется, пока его не открыли, см. [Порты в брандмауэре](interfaces.ru.html#порты-в-брандмауэре) |
| Базовый путь | что идёт после порта перед именем подписки, `/sub/` по умолчанию; на порту панели не может быть `api`, `assets` или путём панели |
| Сертификат | цепочка и ключ для своего порта; пусто - сертификат панели |
| Интервал обновления, ч | как часто клиент перечитывает подписку, 12 по умолчанию, 1-720 |
| Заголовок профиля | имя, которое клиент даёт подписке; пусто - хост адреса |

Без своих доменов подписки берут домен панели, а без него - хост, на который пришёл запрос; за обратным прокси это внутренний хост, пока прокси не назван в `Web__Proxies`, см. [Сервер](server.ru.html#первый-старт). Подписки отвечают и на TCP-порту сервисов каждого интерфейса.

## Что отвечает подписка

`GET /<путь>/<подписка>` отдаёт base64 от ссылок `vpn://`, по одной на строку: по ссылке на каждого включённого клиента с приватным ключом на включённом интерфейсе; имя конфигурации в ссылке даёт шаблон имени с вкладки «Сервер». Подписка, у которой нет ни одного клиента, отвечает 404; подписка, все клиенты которой выключены, отвечает пустым телом, и приложение помечает их конфигурации ушедшими. Имя подписки - секрет: кто читает подписку, получает приватные ключи её клиентов.

| Заголовок | Что несёт |
|---|---|
| `Subscription-Userinfo` | `upload` и `download` - трафик клиентов за сегодня; `total` - их ограничения в день вместе, 0, если у кого-то нет ограничения; `expire=0` |
| `Profile-Update-Interval` | интервал обновления в часах |
| `Profile-Title` | заголовок профиля в base64, если задан |

Браузер, который просит `text/html`, получает вместо base64 страницу: заголовок профиля, имя подписки, число конфигураций, интервал обновления и трафик за сегодня против ограничений, и карточки, как на вкладке «Экспорт» клиента: QR-код адреса подписки и по две на конфигурацию, файл `.conf` и ссылка `vpn://`, с копированием и сохранением. Страница говорит по-русски с браузером, который просит русский, следует его светлой или тёмной схеме и ничего не загружает со стороны. Приложение AmneziaGeo просит `text/plain` и получает base64.

## Подписка клиента

Новый клиент получает свою подписку: 16 латинских букв и цифр; её получает и клиент из импорта. Поле «Подписка» в настройках клиента меняет её: одно имя у нескольких клиентов собирает их в одну подписку, пустое выводит клиента из подписок, кнопка рядом делает новое имя. Имя - латинские буквы, цифры, дефис и подчёркивание, до 64 знаков, с учётом регистра. Адрес подписки показывает вкладка «Экспорт» клиента QR-кодом рядом с файлом и ссылкой, пока подписки включены. Сценарий - [Подписка на несколько устройств](../recipes/family.ru.html).

## Отказы

| Сообщение | За чем стоит |
|---|---|
| Порт вне диапазона 1-65535; Порт занят другой службой; Подписки не встали на этот порт, причина в журнале | порт |
| Адрес, на котором слушать, не разобран; Домен не разобран | адреса и домены |
| Путь подписок не разобран; На этом порту путь уже занят | путь на порту панели занят ею самой или WebSocket интерфейса |
| Сертификат берётся парой путей: цепочка и ключ; и отказы файлов сертификата, как на вкладке «Сертификаты» | сертификат |
| Интервал вне диапазона 1-720 ч; Заголовок длиннее 128 знаков или с переводом строки | интервал и заголовок |
| Подписка из латинских букв, цифр, дефиса и подчёркивания, до 64 знаков | имя подписки клиента |
| Сетевой экран сервера не принял порт | брандмауэр |
