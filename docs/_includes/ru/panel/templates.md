# {{ page.title }}

Шаблон несёт то, что в файле клиента не принадлежит одному клиенту: `AllowedIPs`, серверы имён, размер пакета и keepalive, а ещё пресеты маршрутизации, которые получает приложение AmneziaGeo. Клиент указывает на шаблон, а не держит копию: правка шаблона меняет файлы всех его клиентов, и подписка отдаёт новый файл сразу, потому что файл собирается в момент запроса. Свежая панель начинает с шаблона `default`.

Вкладка «Шаблоны» страницы «Клиенты» перечисляет шаблоны с их `AllowedIPs`, DNS, MTU, keepalive и числом клиентов; имя ведёт в настройки, «Добавить» открывает новый, «Дублировать» в меню строки делает копию «<имя> копия». Поле «Шаблон» в настройках клиента выбирает его шаблон, «По умолчанию» оставляет клиенту настройки интерфейса.

## Основное

«Имя» - до 64 знаков, одно на панель.

## Маршрутизация

Записи шаблона - то, что клиент отправляет в туннель. Диапазоны не пишутся руками: шаблон держит список записей, как списки клиента AmneziaGeo, и сам разворачивает их в адреса.

| Запись | Пишется | Даёт |
|---|---|---|
| GeoIP | `geoip:ru` | диапазоны страны или сети из гео-баз |
| GeoSite | `geosite:youtube` | адреса, в которые разрешаются домены категории |
| Сеть | `cidr:10.0.0.0/8` | себя |
| Адрес | `cidr:203.0.113.10` | себя |
| Домен | `domain:example.com` | адреса, в которые разрешается имя |

Сеть, адрес или имя, набранные без приставки, получают её при добавлении; ссылка оставляет свой хост. Имена спрашиваются в обоих семействах через внешние серверы резолвера панели; из категории geosite спрашиваются только домены и точные имена, у ключевых слов и выражений адреса нет. Один проход спрашивает до 4000 имён и кончается через минуту; имя без ответа считается не найденным. Адреса, в которые пакет через туннель не пойдёт (петля, нулевой, link-local, групповые, широковещательный), отбрасываются; частный адрес остаётся, потому что имя внутреннего резолвера может вести к хосту за сервером.

Что дали записи, сворачивается в наименьшее число диапазонов и хранится с шаблоном вместе с записями, которые ничего не дали, и временем прохода: «Обновлено <время>», «Не нашлось адресов: <список>». Это и идёт в `AllowedIPs` каждого клиента шаблона; пустой список даёт `0.0.0.0/0`, а клиенту с адресом IPv6 ещё `::/0`. Список пересчитывается при сохранении и кнопкой «Обновить»: имена переезжают и гео-базы обновляются, а файлы клиентов меняются только после пересчёта.

Пока шаблон правится, панель считает, что даёт каждая запись: «Адресов: N» у записи и у шаблона целиком, «Показать содержимое» раскрывает первые адреса или имена категории («Записей нет: категории нет в загруженных базах»). Больше 12000 диапазонов - «возможно замедление скорости», больше 16000 - «слишком много адресов, сохранить нельзя». Шаблон не больше 256 записей.

«Пресеты маршрутизации» - списки, которые получает приложение AmneziaGeo клиента шаблона, в порядке выдачи, пока маршрутизация идёт на клиенте, см. [Пресеты маршрутизации](presets.ru.html); «Пресетов нет: добавьте их во вкладке «Пресеты маршрутизации»», пока их не завели.

## Сеть

| Поле | Что задаёт |
|---|---|
| DNS | серверы имён клиента; пусто - резолвер панели, когда он отвечает внутри туннеля, иначе `1.1.1.1` и `1.0.0.1` |
| MTU | 576-9000; пусто - 1420 |
| Keepalive | 0-65535 секунд, 0 выключает; пусто - 25 |

Ключи, адрес клиента, адрес интерфейса и обфускация всегда идут от интерфейса: они должны сходиться с сервером.

## Удаление

Шаблон, который взял хотя бы один клиент, не удаляется: «Шаблон уже используется». Сначала клиентам выбирается другой шаблон.

## Отказы

| Сообщение | За чем стоит |
|---|---|
| Имя шаблона пустое или длиннее 64 знаков | имя |
| Это не ключ гео, не сеть, не адрес и не домен; В шаблоне не больше 256 записей | записи |
| Это не адрес сервера имён; MTU вне диапазона 576-9000; Keepalive вне диапазона 0-65535 | сеть |
| Такого пресета маршрутизации нет | шаблон называет пресет, которого нет |
