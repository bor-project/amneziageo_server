## Updates

The server asks GitHub (api.github.com) for new versions by itself and downloads them from there (github.com, and ghcr.io images for Docker). The request carries nothing about your server or your clients. GitHub sees what any website sees: the address the request came from and the name of the program.

The other addresses the server reaches by itself are listed in "Privacy".
