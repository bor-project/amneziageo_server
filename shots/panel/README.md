# Кадры панели для сайта

Каждый кадр снимается одним заданием `frames/<имя>.mjs` на любом языке панели. Задание не зависит от языка: оно
открывает страницу по адресу панели, заполняет поля по их `id`, а подписи кнопок берёт из словарей панели
(`amneziageo-web/src/i18n/<язык>.ts`) по ключу.

## Где что

| Путь | Что |
|---|---|
| `frames.txt` | порядок съёмки и что на каждом кадре |
| `frames/<имя>.mjs` | задание кадра: где он стоит на сайте, что видно, что нужно стенду, адрес страницы и шаги |
| `languages.json` | языки съёмки |
| `shoot.mjs` | съёмка: язык, подмены, проверка, сохранение |
| `kit/cdp.mjs` | управление вкладкой Chrome по протоколу отладки |
| `kit/mask.js` | подмена имён и адресов стенда на странице |
| `kit/form.mjs` | заполнение полей формы без сохранения |
| `kit/fake.mjs` | выдуманные конфигурация, ссылка `vpn://` и адрес подписки для QR-кодов |
| `local/` | настройки стенда, в git не идут: `stand.json` (адрес панели, порт отладки, номера объектов), `mask.json` (подмены) |
| `out/<язык>/` | снятые кадры до просмотра, в git не идут |

На сайте кадр лежит в `amneziageo-docs/server/assets/img/<язык>/<имя>.png` и вставляется по имени:
`{% include shot.html name="<имя>" alt="..." caption="..." %}`. Шаблон берёт кадр на языке страницы, без него -
английский; проверка сайта (`tools/site.sh check` в amneziageo-docs) считает такие кадры.

## Стенд

- Панель с двумя интерфейсами, клиентами (в сети, с шаблоном и без), шаблоном с гео-ключами и маршрутизацией по
  именам, включённым резолвером и загруженными списками Geo. Набор ничего на стенде не сохраняет: формы правила,
  канала и базовых списков заполняются и не сохраняются, проверка маршрута только читает правила.
- Chrome со своим профилем и портом отладки на этой же машине, в нём выполнен вход в панель:
  `chrome.exe --user-data-dir=<профиль> --remote-debugging-port=9333 --remote-debugging-address=127.0.0.1 <адрес панели>`.
  Язык и тему набор ставит в `localStorage` вкладки, настройки панели не меняются.
- Node 22 или новее (WebSocket из коробки) и `node_modules` в `amneziageo-web` (`npm ci`): QR-коды рисует тот же
  пакет `qrcode`, что и панель.
- `local/stand.json`:

```json
{
 "url": "https://<адрес панели>/",
 "port": 9333,
 "ids": { "interface": 2, "client": 45, "clientOnline": 48, "clientPlain": 20, "template": 2 },
 "names": { "clientOnline": "<имя клиента в сети>" }
}
```

  `interface` - интерфейс для формы, `client` - клиент с шаблоном, `clientOnline` - клиент с шаблоном и трафиком
  (его имя в `names` нужно проверке маршрута), `clientPlain` - клиент без шаблона с адресом подписки,
  `template` - шаблон с маршрутизацией по именам.
- Для кадров окна отдельного сервера обновлений (`updates-window-login`, `updates-window`): сервер с окном и двумя
  выпусками, в `local/stand.json` его адрес и файл его токена:
  `"updates": { "url": "https://<адрес сервера>:<порт>/<путь окна>/", "tokenFile": "<файл с токеном>" }`. Окно
  открывается в той же вкладке, вход по токену делает задание.
- `local/mask.json`: что подменять на странице, список `{ "from", "to", "mode", "check" }`. `mode`: `sub` - вхождение
  без учёта регистра, `word` - отдельное слово (для коротких имён), `re` - регулярное выражение; `check: false`
  снимает строку с проверки утечек; `frames: [<имя>, ...]` - подмена только этих кадров, она идёт раньше общих
  (так одно имя стенда получает на разных кадрах разные выдуманные имена). Сюда идут имена и адреса стенда, имена клиентов, шаблонов, каналов и токенов,
  публичные адреса клиентов, диапазоны шаблонов не из гео-баз. Подменять на выдуманные имена и адреса из диапазонов
  для документации (`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`, `2001:db8::/32`, `example.com`).

## Снять язык

1. Открыть Chrome стенда и войти в панель.
2. `node shots/panel/shoot.mjs ru` - все кадры из `frames.txt`; `all` - все языки; один кадр:
   `node shots/panel/shoot.mjs ru clients`.
3. Кадр не сохраняется, если после подмен на странице осталось имя динамического DNS, публичный адрес не из
   диапазонов для документации, строка из `mask.json` или ключ, который был на странице до подмен. Ключи меняются на
   выдуманные сами, QR-коды заменяет задание экспорта.
4. Каждый кадр в `out/ru/` смотреть глазами: нет ли адресов, имён, ключей, QR настоящих конфигураций.
5. Годные кадры скопировать в `amneziageo-docs/server/assets/img/ru/`.

## Новый язык

1. В панели есть словарь `amneziageo-web/src/i18n/<язык>.ts`.
2. Строка в `languages.json`.
3. `node shots/panel/shoot.mjs <язык>`, просмотр, кадры в `amneziageo-docs/server/assets/img/<язык>/`.
4. На страницах языка те же вставки `shot.html` по имени, подписи `alt` и `caption` на этом языке.

## Новый кадр

1. Задание `frames/<имя>.mjs` по образцу: шапка (где на сайте, что видно, что нужно стенду) и `export default`:
   - `route` - адрес страницы или функция от `stand.json`;
   - `app: "updates"` - кадр окна сервера обновлений: `route` идёт от `updates.url`, а не от адреса панели;
   - `steps(ctx)` - шаги до подмен: заполнить поля (`kit/form.mjs`), нажать кнопку по ключу словаря `ctx.t[...]`;
   - `after(ctx)` - шаги после подмен, например замена QR-кодов (`kit/fake.mjs`);
   - `mask` - подмены только этого кадра без имён стенда, они идут раньше общих (подмены с именами стенда - в
     `local/mask.json` с полем `frames`);
   - `publicAddresses` - регулярные выражения публичных адресов, которые кадр может показать (ответ проверки
     маршрута);
   - `view` - размер окна, если не 1440x900; высота `"fit"` - по высоте страницы, чтобы полоса кнопок формы не
     уходила к низу высокого окна; `clip(ctx)` - область снимка.
2. Строка в `frames.txt`, снять все языки.
